# Actividad_2-Aplicacion-web-interactiva-con-API

Fecha de entrega: 9/7/2026
Objetivo: desarrollar una aplicación web interactiva que consuma la API de Rick and Morty.

Partes:

1) Inicio de sesion, crear nueva cuenta, validacion de los daots y recuperacion de cuenta.

2) Buscador de personajes donde: visualizes los datos(ID, Nombre, Especie, Género y Tipo de cada personaje) y ver ficha completa de un personaje que incluye informacion detallada y fotografia, buscar por nombre de personaje, opcion para ordenar la tabla de manera ascendente y descendente. Por ultimo, funcionalidad para modificar y guardar los datos del personaje consultado.

3) Modo offline, Resiliencia(implementación de estrategias de almacenamiento en caché para garantizar el almacenamiento de datos y permitir que las distintas secciones de la aplicación carguen y funcionen correctamente sin conexión a internet), modo claro/oscuro y por ultimo un sistema 100% responsive.



Consideraciones tecnicas:

- Las tecnologías permitidas son HTML5, CSS3 y lenguaje JavaScript. Todas
las funciones, elementos y estilos deben implementarse programando o
maquetando con estas tecnologías puras.

- Se puede usar librerías o preprocesadores de estilos: Bootstrap, Tailwind
CSS, etc .

- Está prohibido el uso de: Cualquier marco de trabajo (framework) o de desarrollo de software: React, Angular, Vue.js, Svelte, Solid.js, Next.js, Nuxt, js, entre otros.
